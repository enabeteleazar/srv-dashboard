Démarrage rapide

Depuis homebox, Neron tourne en local : l'API est sur 127.0.0.1.

# état de tous les projets
curl -s -H "Authorization: Bearer $DASHBOARD_API_TOKEN" -H "X-Client: neron" \
     {{ api_base }}/projects | jq '.[] | {name, up, status}'

# chiffres clés (pour une réponse vocale : « 11 projets, 3 en ligne »)
curl -s -H "Authorization: Bearer $DASHBOARD_API_TOKEN" -H "X-Client: neron" \
     {{ api_base }}/summary

# déployer en preview, sans attendre la fin
curl -s -X POST -H "Authorization: Bearer $DASHBOARD_API_TOKEN" -H "X-Client: neron" \
     -H "Content-Type: application/json" -d '{"action":"deploy","wait":false}' \
     {{ api_base }}/projects/duoLingo/actions

# suivre l'action lancée
curl -s -H "Authorization: Bearer $DASHBOARD_API_TOKEN" {{ api_base }}/activity/42

L'en-tête X-Client est repris tel quel dans la colonne « source » du journal : les actions de Neron sont donc distinguables de celles lancées à la main.

POST/syncScanner /srv et enregistrer les nouveaux dossiers

Client Python

Fourni dans /srv/clients/srv_dashboard_client.py — zéro dépendance (urllib).

from srv_dashboard_client import SrvDashboardClient

srv = SrvDashboardClient("{{ api_base }}", token=os.environ["{{ env_key }}"])
srv.summary()                              # {'total': 11, 'up': 3, ...}
srv.projects(status="active")              # liste filtrée
srv.run_action("duoLingo", "deploy")       # renvoie l'activité (running)
srv.wait_for(activity["id"])               # sonde jusqu'à ok/error
